# 🎬 Netflix Clone

A responsive Netflix-inspired web application built using **HTML, CSS, and JavaScript**.  
This project replicates the core UI of Netflix, focusing on modern design, responsiveness, and smooth user interaction across all devices.

---

## 🚀 Features

- 🎥 Netflix-style banner section
- 🔥 Trending movies carousel
- ⬅️➡️ Scrollable movie lists with left & right buttons
- 📱 Fully responsive design (mobile, tablet, desktop)
- 🎨 Clean and modern Netflix-like UI
- 🌐 Language selection button (UI-based)

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**
- **Responsive Web Design**

---

## 📱 Responsive Design

This project is optimized for:
- Desktop 💻
- Tablet 📱
- Mobile 📲  

All sections adjust smoothly to different screen sizes without breaking the layout.
